# 雪团开场校园场景

网页资源：`assets/launch-campus.webp`（174,402 bytes）和 `assets/launch-campus-snow.webp`（205,022 bytes），均为 1024 × 1536。使用内置 image_gen 生成场景，再保持同构图编辑为覆雪版本；Pillow 仅转换为 WebP，未使用网上照片或用户私人图片。场景为 XMUM 风格的艺术演绎，不是校园实拍。

场景在 `index.html`，动画在 `js/00-launch.js`，样式在 `css/app.css`：有纹理的雪团加速接近、冲击时碎雪与粉尘散开、前后景雪花落下、屋顶/椰林/庭院覆雪，显示“xmumer的图鉴”，随后淡出进入应用。画面约 4.65 秒，资产最多等 650ms，独立硬退出上限 5.6 秒。地图和数据在后台并行加载。支持跳过和 Escape，同一标签页会话仅播放一次；减少动态效果设置下显示短暂静态画面。`?splash`（兼容 `?intro=1`）可显式重播用于审阅，分享链接不会携带这个参数。
