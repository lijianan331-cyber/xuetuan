# 雪团界面风格（2026-11-01 定，以后的小改照这个来）

用户的话：在现在的基础上往好里改，不推翻；要好读、好看，有一点苹果那种高级和简约；雪的元素只放一点点。

## 颜色（都在 `css/app.css` 开头的变量里，别写死）
- 主色 `var(--accent)`：美食地图是冰蓝 #2E7DCB，玩乐地图是深一点的雪蓝 #4F63D8。
- 底色 #EEF4FA，卡片白色，浅底 `--surface-2` #F1F6FB；像设置一样的页面（“我的”）用灰底 `--page-grouped` #F3F6FA，上面放白卡片。
- 文字 `--ink` #1B2A3A，次要文字 `--muted` #687A8C。
- 永远是浅色：手机开了深色模式也保持蓝白。

## 字
- 英文和数字用 Plus Jakarta Sans；中文用手机自带的字体（苹方、鸿蒙、MiSans），不再下载思源黑体；“雪团”两个字用站酷庆科黄油体。
- 最粗用到 700（只有评分小胶囊里 11px 的白色数字用 800，为了看得清）。标题 17–22px，正文 14–15px，说明 12.5–13px。

## 形状和阴影
- 圆角按层级：底部面板 22，卡片 16–18，输入框和小卡片 12–14，按钮和标签用胶囊形。
- 卡片外圈用一条很细的线（`--hairline`），不用粗边框；阴影只用 `--snow-shadow` / `--shadow-soft`。
- 地图上的圆按钮 38px，搜索条 50px 高。

## 动效
- 开屏（2026-11-02 改）：像 Instagram / 抖音，全屏雪团蓝渐变，中间雪团子 + “雪团”，底部一句“XMUMer 的图鉴”，飘一点小雪，约 1.2 秒进首页，点一下跳过。
- 开屏之外没有“大动作”。别的动效只回应用户的操作：按下轻轻缩一下、弹出来的面板轻轻放大出现、加载时灰卡片上一道微光。
- 不加一直循环的装饰动画。系统设了“减少动态效果”时全部关掉。

## 雪的元素（就这几处，别再加）
- logo、首页没有分享时的雪团子。列表里的空状态保持一行小字，不放图。

## 文案
- 按钮直接说做什么（“去记录”“发帖”）；空状态告诉人下一步能做什么。
- 用“美食 / 玩乐”，不用“吃 / 玩”。
