## 建议接下来怎么排

1. **先做稳定性验收，不增加大功能。** 真手机慢网连续添加/批量导入、失败重试、返回不丢草稿；用两个真实账号验证私人照片、公开记录、收藏、删除与退出登录。谷歌加载、限额与坐标刷新维护也应检查。公开分享前补足隐私说明、删除及举报的最低可用流程。
2. **再做公开个人主页 + 分享链接。** 这是“同学是谁、去过哪、为什么值得看”的关键缺口，也能把雪团内容发到微信/Instagram，直接检验传播需求。先显示公开记录，继续隔离私人足迹。
3. **随后改善附近发现和时间筛选。** 最近 7/30 天、预算、餐品分类、地图视野列表联动，更直接解决“今天吃什么”。没有近期内容时仍可看全部。
4. **小范围试用后再决定社交。** 先邀请少量朋友填真实记录，观察搜索→收藏、添加完成率与一周内回访。有人持续看内容，再做轻量点赞/评论及举报；不立即做私信/关注大全。
5. **P2 优先分享卡片与收藏夹，再考虑路线和精美地球。** 批量导入与家乡基础版已经提前做了；不要因为计划曾列在 P2 就重写。排行榜、AI 识别、拼车和复杂社交等待真实需求。

当前最重要的缺口是稳定性、他人公开主页与低门槛分享，而不是再增加一种地图模式。以上是当前建议，可根据试用结果调整。
