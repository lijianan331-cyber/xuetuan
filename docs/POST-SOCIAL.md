# 帖子留言、回复与轻量点赞

范围：公开 visits 的互动，仍复用现有帖子、地点和作者。不加私信、关注、消息中心、热度榜或首页互动计数。

## 当前实现

- 帖子详情：点赞/取消点赞、两行留言框、500 字以内纯文字留言、对主留言的一层回复、每次 30 条的“更早的留言”。
- 地点详情的每条公开点评提供“留言”入口，进入相同帖子讨论；私人点评与示例没有公开互动入口。
- 点赞总数只有帖子作者可以读到；所有人都看不到点赞者列表。首页不加数量。
- 未登录可以阅读；点赞、评论、回复、删除自己的评论和举报可使用匿名游客账号。第一次操作自动准备游客身份并继续，不强制 Google 登录。游客仍不能发布公开帖子，可保存私密记录；私信和管理操作仍需已验证的正式账号。
- 留言者可删除自己的留言；帖子作者可删除帖内留言。正文清空，页面显示“这条留言已删除”，已有回复保留。
- 举报分广告刷屏、辱骂骚扰、泄露隐私、其他；每个账号对同条留言只记一条举报。举报者身份不返回公开接口。
- 管理员在“我的 → 留言举报”查看未处理举报，能忽略、删留言或删留言并封禁账号/已记录浏览器。沿用原后台管理员校验与封禁表，留审计记录。
- 请求失败可重试；留言在当前页面会话保留，退出账号清空。重复点击被禁用，重试同一留言使用同一 UUID，防止超时后重复发表。
- 20 秒超时释放界面，迟到结果不覆盖当前页；切换帖子/账号隔离请求和缓存。仅进入帖子或主动刷新时拉取互动，不后台轮询。

## 数据与权限

迁移：`supabase/migrations/20261102150713_post_interactions.sql`。**用户已同意，线上已应用（2026-11-02）。**

新增三张私有表：`xuetuan_guard.post_likes`、`post_comments`、`comment_reports`。全部开 RLS，不授予 anon/authenticated 直接表读写权限。

前台仅调用四个 invoker RPC：`xuetuan_post_social`、`xuetuan_social_write`、`xuetuan_comment_reports`、`xuetuan_moderate_comment`。对应的受控 definer 函数位于未暴露的私有 schema，固定空 search_path，逐次检查账号/公开状态/对象归属/管理员权限。私有 schema 的 usage 不代表私有表读写权限；内部限流函数不授权直接调用。

写入从 `auth.uid()` 决定作者，并查 `auth.users.is_anonymous` / `email_confirmed_at`；不信任前台作者 ID 或 user_metadata。点赞每账号每帖最多一条；回复必须指向同帖未删除主留言。数据库只认仍公开的帖子，改为私密后读写都拒绝；管理员举报列表也不泄露私人帖子。帖子删除时关联互动级联删除。

防刷：留言每分钟 6 条、每天 100 条；举报每分钟 3 次、每天 20 次；其他互动每分钟 60 次、每天 500 次。复用 `write_windows` 的原子计数、账号/浏览器封禁和浏览器标识记录。浏览器标识能被清除，不宣称硬件封禁。

不改旧记录、金额、照片、可见范围、账号，不新接付费服务。上线需先迁移再发布前端；数据库尚未准备时帖子主体仍可读，互动显示未启用并可重试，不假报成功。
