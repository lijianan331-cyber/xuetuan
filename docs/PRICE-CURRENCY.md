# 原币金额与展示换算

已完成的界面：
- 日本、韩国、泰国、印尼、台湾地区默认使用 MYR，可改选 JPY / KRW / THB / IDR / TWD；中国大陆、美国等保留原来的本地货币默认。
- 人民币界面显示 RMB，数据库按 ISO 标准保存 CNY；其他货币显示官方代码。
- 首页、帖子、探索地点详情和点评中的价格可点击，在 MYR 与当地货币之间切换；换算显示“约”，采用预算估算汇率，不是实时汇率。
- 切换展示不会写数据库、改原金额或累计舍入误差；编辑和草稿保留币种。不同币种先统一成 MYR 算均价和预算筛选。
- 批量添加可以选择币种，支持较大的本币金额；合并照片组保留价格及币种。
