# 分页、地图区域读取与运行检查

首页每页20条，最多40条；按活动时间/ID或评分/活动时间/ID使用游标。修改文字、评分和公开范围不改变活动时间；新增照片或修改到访日期按原有规则计算。新列由触发器计算，回填时保留旧审计时间及触发器状态。

探索地图按可见经纬度和模式读取。10级以下使用空间聚合，数量来自所有符合权限的地点；10级及以上按250地点游标读取摘要，不传点评正文。启用筛选时读取当前区域的地点摘要，在客户端使用现有分类、Halal、距离和货币规则，避免改变原有筛选含义。日期变更线支持东西边界跨180度。

地点评分/条数/照片数由完整的权限内记录聚合，与加载了几页点评无关。地点点评每页20条，可继续加载图片和点评。本人足迹和他人公开主页按作者单独读取，每批250条，不读取所有人的完整记录；本人全球足迹/国家/分享总计保持完整。个人列表每次显示80条，可继续展开，标题统计不截断为80。

旧接口或迁移未启用时保持原有读取方式。普通网络错误不悄悄降级为全量下载；账号切换和迟到请求受身份/请求序号保护。页面关闭后启用新离线外壳。没有新增数据表或放宽现有公开范围。

## 检查方式

- `python tests/test_app.py`：现有全站回归，保留旧接口兼容性。
- `node tests/test_bounded_reads.mjs <PGlite的dist/index.js路径>`：真实Postgres/RLS、游标、总计和1k/10k合成数据查询。
- `python tests/test_bounded_reads.py`：真实隔离Postgres/RLS的HTTP服务，手机视口、150ms延迟/限速、翻页、竞争请求、个人分享与大账号。
- `python tests/test_offline.py`、`node tests/test_media_urls.mjs`、`python tests/test_map_clusters.py`：离线、签名权限和真实地图回归。
- 在原A链接加 `&perf`：本地显示数据请求数、最近耗时/P95、逻辑JSON字节数、地图返回项和首页加载条数。只有当前浏览器保留这些指标，不上传内容、位置或身份日志。
- 迁移启用后可运行 `python tools/check_read_service.py --live --output tests/shots/read-live.json`：分1/4/8并发，每轮16次匿名只读请求；失败或P95超过5秒就停止，不产生帖子/图片。报告只含状态和性能数字。可使用`--endpoint`检测隔离测试服务。
- 项目所有者可用 `tools/read_health.sql` 查看数据库/媒体聚合大小、估计行数、死行、索引使用和连接信息；同时在Supabase/Vercel查看CPU、5xx、P95及实际额度内的存储/流量。媒体字节数依赖Storage元数据，账单流量以提供商为准。

## 结论边界

本机PGlite是Postgres WASM，单实例事务串行；其HTTP并发检查不能冒充云端原生多连接压测。浏览器限速测试使用合成数据和测试地图，不能冒充真实手机GPU或国内线路测试。线上匿名探测只代表当前数据量的短时读取表现，不证明多人同时上传的容量。大规模写入/上传压测应在独立环境进行，不能向有真实用户的库伪造大量帖子或图片。

发生问题时可先回滚前端提交；新增列/索引/只读接口可保留，不删旧记录、不改变RLS。不要上线旧的全量read_snapshot_stamp来掩盖分页问题。迁移需要用户按AGENTS.md确认后执行。
