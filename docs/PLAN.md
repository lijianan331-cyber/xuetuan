# 雪团 改进方案

对照 `docs/PRD.md`（V1.0）和当前的 `index.html`（v1，单文件原生 JS）写成。
标 **[需求]** 的来自 PRD，标 **[建议]** 的是额外建议，可以不采纳。

## 一、现状

- 一个 HTML 文件，原生 JavaScript，没有构建步骤。
- 地图：MapLibre GL JS 5.24.0（jsDelivr 固定版本）+ OpenFreeMap 底图（positron / liberty）。
- 支持地球视图一路放大到街道；点多时合并成带数字的聚合点，放大后展开。
- 数据存在浏览器 localStorage，照片压缩后存在 IndexedDB；可以导出 / 导入 JSON。
- 没有后端，没有账号，所以“公共地图”现在只有本机能看到。
- 中英双语，中文优先；支持深色模式；手机是底部抽屉，电脑是左侧面板。
- `tests/test_app.py`：Playwright + 假的 MapLibre，101 项检查。

## 三、数据设计

- **places 地点**：一个真实地点一行；名称、坐标、精度（exact / area / city）、吃 / 玩、分类、OSM 编号（可空）。
- **visits 足迹记录**：某人对某地点的一条记录；评分 0–5、人均、评论、照片、公开 / 私密、日期。
- **wishlist 收藏**：只记“谁收藏了哪个地点”，不算去过。
- **profiles 用户**：昵称、头像、家乡（国家 / 地区 / 城市 / 区）。

图钉颜色：公共地图用公开记录平均分；我的地图用我自己的分；收藏地图用公共平均分。
只有私密记录的地点不出现在公共地图（用 Supabase RLS 保证，上线前用两个账号互测）。

防重复地点：
1. 已有：新增前按缩放级别查附近（街道约 60 m，区域约 800 m，城市约 15 km）。
2. [建议] 按名字搜 OSM 地点，同一 OSM 编号直接算同一家；小店查不到就手动插针。
3. [建议] 管理员“合并地点”，底下所有记录保留。

## 四、步骤

### 第 1 步：纯前端（不需要注册任何账号）
- [x] 改名“雪团”

- [x] 编辑自己的记录
- [x] 按评分、距离筛选；距离分层：步行 ≤1.5 km / 短途打车 ≤10 km / 中距离 ≤40 km / 更远 [建议，数字待调]
- [x] 按名字搜地点 [建议]
- [x] 把读写数据的代码集中到一个 `store` 对象里，第 2 步只换它的实现，不动界面
- [x] 测试同步更新

第 1 步的实现说明：
- `store` 的读是同步的（从内存缓存读），写都返回 Promise。第 2 步换 Supabase 时，`init()` 负责把数据拉进缓存，写操作改成调接口，界面代码不用动。
- 数据格式升到 v2：以前“没打分”存成 0，现在 0 是合法分数，没打分是 `null`。旧数据和旧备份会自动转换。新增 `wishlist`。
- 存储键名和 IndexedDB 名沿用改名前的，避免读不到已经存下的数据。
- 地图颜色：0 灰 → 2.5 橙 → 5 红，按 0.5 分一档；示例数据没有分数，显示浅灰。
- “按名字搜地点”用的是 Photon（基于 OpenStreetMap 的免费搜索，不需要 key）。选中结果会带上 OSM 编号，同一编号直接算同一个地点。Photon 是公共服务，用量大了要换自建或付费服务。
- 距离筛选按到 XMUM 的直线距离分四档，只在“吃”里出现。

## 五、费用与限制

- Supabase 免费版：数据库 500 MB、存储 1 GB（约五千张压缩照片）、每月流量 5 GB、5 万月活。**一周没人访问会暂停**，要去后台恢复。
- Vercel Hobby：只限个人、非商业。挂佣金链接或广告就要升级 Pro。
- OpenFreeMap：免费，不需要 key；要保留 “OpenFreeMap © OpenMapTiles © OpenStreetMap” 署名。
- 以上额度是 2026 年的数字，动手前再到官网确认一次。
